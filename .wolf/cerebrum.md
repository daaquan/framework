- **[2026-05-30] BladeOne writes compiled `.bladec` into the ctor's `$compiledPath` dir** — when testing a Blade render with a tmp fixture, the compile dir = the path you pass as `storagePath('framework/views')`. Clean THAT exact dir in `afterEach` (and its parent chain), else `rmdir` warns "directory not empty" and Pest flags the test. `sys_get_temp_dir()` in this harness returns `/tmp/claude-.../...` (not bare `/tmp`), so glob patterns like `/tmp/phare_*` won't match the real path. See [[buglog bug-050]].

- **[2026-05-29] `@dataProvider` docblock fails in this Pest 2 / PHPUnit setup** with `ArgumentCountError` (provider not fed into the test method) for plain `PHPUnit\Framework\TestCase` classes like `tests/Validation/ValidatorTest.php`. Don't use `@dataProvider`. Instead loop over a private case-array helper inside one test method (`foreach ($this->cases() as $label => [$a,$b]) { ...assert with $label message... }`). See [[buglog bug-048]].
- **[2026-05-29] phpstan "0 regression vs baseline" is the gate, NOT "0 errors"** — `src/Phare/Validation/Validator.php` carries 62 pre-existing level-8 `missingType`/`mixed` errors. New methods in the file's untyped sibling style ADD errors (+2/method → +30) which trips the gate. Fix: type NEW code properly (`mixed $value` + `/** @param list<string> $parameters */`) so it contributes 0 new errors; leave the untyped siblings alone (no noisy whole-file refactor). Always `git stash`→phpstan→`stash pop`→phpstan to diff counts before claiming clean.
- **[2026-05-29] NEVER symlink `vendor/` into a git worktree** — Composer's generated `vendor/composer/autoload_psr4.php` computes `$baseDir` from the realpath of the autoload file. PHP resolves the symlink on `require`, so `__DIR__` points at MAIN's `/opt/framework/vendor/composer`, making `Phare\` → `/opt/framework/src/Phare` (MAIN). Result: stock `./bin/pest` in the worktree silently loads MAIN's source, NOT the worktree's edits — every "green" run tests the wrong tree. Proof: `php -r 'require "vendor/autoload.php"; echo (new ReflectionClass(Phare\Container\Container::class))->getFileName();'` shows the main path. Fix: run a real `composer install` in the worktree (`vendor` is gitignored; ext-phalcon is a system extension so install only fetches PHP deps, ~fast with warm cache). When setting up a PHP worktree, do `composer install` from the start — do not symlink. See [[buglog bug-049]].
